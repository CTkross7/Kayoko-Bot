# 🐾 Kayoko-Bot (카요코 봇)

<블루 아카이브>(Blue Archive) 세계관을 소재로 한 **비공식 2차 창작 디스코드 봇**입니다.
"냥이 납치(수집)"를 중심으로 한 자체 RPG 콘텐츠와, AI 페르소나 기반 캐릭터 **카요코**와의 대화 기능을 제공합니다.

> ⚠️ 본 프로젝트는 현재 개발/운영 중이며, 아래 기능 목록은 코드 기준으로 작성되었습니다. 세부 수치나 명령어는 지속적으로 변경될 수 있습니다.

## ⚠️ 비공식 프로젝트 및 저작권 고지

- 본 프로젝트는 **넥슨게임즈(Nexon Games) / 요스타(Yostar)** 등 <블루 아카이브>의 원 저작권자와 **어떠한 제휴, 후원, 협력 관계도 없는 비공식 팬 프로젝트**입니다.
- <블루 아카이브>에 등장하는 캐릭터명, 세계관, 설정 등에 대한 저작권 및 상표권은 전부 원 저작권자에게 있습니다.
- 본 저장소에서 제공하는 것은 **개발자가 독자적으로 설계한 게임 시스템(레벨링, 전투, 경제, 미궁, 보스 레이드 등)과 소스 코드**이며, 원작의 이미지·음원·시나리오 등 저작물 원본은 포함하지 않습니다. (봇 운영 시 사용자가 직접 준비해야 하는 리소스가 있을 수 있습니다.)
- 원 저작권자 또는 배급사로부터 게시 중단 요청이 있을 경우, 즉시 관련 콘텐츠를 삭제하거나 저장소를 비공개로 전환합니다.
- 본 README 및 코드는 팬 활동의 투명성을 위해 공개되며, 상업적 이용을 목적으로 하지 않습니다.

## 📖 소개

Kayoko-Bot은 디스코드 서버 안에서 즐기는 **경량 방치형/수집형 RPG 봇**입니다.
유저는 냥이를 납치(수집)하고, 레벨업과 스킬 트리를 통해 성장하며, 전투·미궁·주간 보스 레이드 등의 콘텐츠를 진행합니다. 여기에 더해 Gemini 기반 AI 컴패니언 **카요코**가 대화 상대이자 봇의 마스코트 역할을 합니다.

## ✨ 주요 기능

### 🐱 냥이 납치(수집) 시스템
- 반응속도 기반 미니게임으로 냥이를 포획 (완벽/그레이트/굿 판정에 따른 성공률 보정)
- 일반 ~ 신화까지 6단계 희귀도, 등급별 판매가/획득 경험치 차등 적용
- 장소별 연출 메시지, 페이크(가짜 등장) 이벤트로 몰입감 부여

### 📈 성장 & 스킬 시스템
- 레벨 1~70, 후반부 구간 경험치 요구량 가중치 적용
- 추적/전투/무역 3계열 스킬 트리와 스킬 포인트 배분

### ⚔️ 전투 & 미궁 & 주간 보스
- 난이도별 전투 콘텐츠 (레벨 제한, 쿨다운 적용)
- 층수 진행형 미궁(던전) 콘텐츠
- 주간 리셋되는 보스 레이드 (보스별 고유 스탯·보상 테이블)

### 🏪 상점 & 도박 & 경제
- 장비/소모품 구매, 판매가 밸런스 조정
- 베팅형 미니게임(도박), 소지금 소프트캡 적용

### 🏆 성장 동기부여 요소
- 단계별 튜토리얼 온보딩
- 수집/전투/미궁/레벨 관련 도전 과제(업적) 시스템
- 자동 납치(방치형 진행), 출석/투표 보상 및 연속 보너스·마일스톤 보상

### 🛡️ 서버 운영 도구
- 신규 유저 인증, 환영 메시지, 공지 채널 관리
- 서버별 봇 활성화/비활성화 토글 (관리자 권한 커맨드는 예외 처리)
- 유저 차단(밴) 시스템 및 사유/기간 안내 임베드

### 🕵️ 안전 & 운영 관리
- 매크로/자동화 패턴을 탐지하는 자체 안티치트 시스템 (커맨드 빈도, 반응 패턴 등 분석 후 자동 경고/차단)
- 부적절 발화를 감지해 반복 시 API 호출을 절약하는 모더레이션 엔진

### 🤖 AI 페르소나 "카요코"
- Google Gemini 기반 대화 기능, 여러 API 키를 자동 검증·로테이션하여 장애 대응
- 단기/장기 기억 및 채널 단위 맥락(RAG 지식베이스 회상) 반영한 대화
- 실제 타이핑처럼 느껴지는 응답 딜레이/청크 분할 연출
- 유저별 일일 대화 횟수 제한 및 과속 요청 쿨다운

## 🛠️ 기술 스택

- **언어/런타임**: Python
- **디스코드 연동**: discord.py (Slash Command / Cog 구조)
- **AI 대화**: Google Generative AI (Gemini) — 대화 모델 + 임베딩 모델
- **데이터 저장**: JSON 파일 기반 (별도 DB 서버 불필요)
- **외부 연동**: 디스코드 봇 리스트 서비스(디스호스트) 통계 자동 전송, Webhook 알림

## 🤖 AI 페어 프로그래밍 사용 고지

이 프로젝트는 개발 과정에서 AI(LLM 기반 코딩 어시스턴트)를 페어 프로그래머로 활용했습니다. 투명성을 위해 역할을 아래와 같이 구분해 명시합니다.

**개발자가 직접 설계·결정한 부분**
- 게임 밸런스 수치 (레벨업 경험치 곡선, 희귀도별 확률·보상, 일일 제한량, 스킬 효과 수치 등)
- 전투 시스템의 속성/상성 구조 및 상호작용 설계
- 전체 시스템 아키텍처 (커맨드 계층 – 게임 시스템 계층 – 데이터 계층 분리, 안티치트/모더레이션 정책 등)
- 카요코 캐릭터의 페르소나, 세계관, 대사 톤

**AI가 구현을 보조한 부분**
- 반복적인 보일러플레이트 코드 (Cog 등록, 임베드 생성 헬퍼, 예외 처리 템플릿 등)
- discord.py API 호출부 및 Gemini API 연동 코드의 초안 작성·구조화
- 리팩토링, 예외 처리 보강, 문서 정리 보조

즉 **"무엇을 만들고 어떻게 밸런스를 잡을지"는 개발자의 판단**이며, AI는 그 판단을 실제로 동작하는 코드로 옮기는 과정을 보조하는 도구로 사용했습니다.
